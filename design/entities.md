# Сущность: Товар (Product)

| Название поля | Тип (C#)  | Тип в БД (SQL) | Описание / Ограничения |
| :--- | :--- | :--- | :--- |
| Id | `int` | `INT PRIMARY KEY` | Уникальный идентификатор (Артикул) |
| Name | `string` | `VARCHAR(255)` | Название товара (обязательное поле) |
| Category | `string` | `VARCHAR(100)` | Категория товара |
| Price | `decimal` | `DECIMAL(10,2)` | Цена товара (не может быть отрицательной) |
| InStock | `bool` | `BOOLEAN` | В наличии (true/false) |
